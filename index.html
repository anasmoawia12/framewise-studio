How the tracking works: this in-browser version scores each region of every frame by skin-tone likelihood and local motion, then smooths that point over time so the crop pans instead of jumping. It's a lightweight stand-in for real face-detection AI — accurate enough for a single clear subject, less precise with busy backgrounds or multiple people. A backend version (Python + proper face detection) can plug in for production-grade accuracy — happy to wire that up next if you want it hosted for real use.
